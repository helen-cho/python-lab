● 데이터 분석과 시각화.

AI 데이터 분석과 시각화는 방대한 원시 데이터(Raw Data)에서 인공지능 기술을 활용해 유의미한 패턴을 찾아내고(분석), 이를 차트나 그래프 등 시각적 형태로 변환하여 이해도를 높이는(시각화) 일련의 자동화된 과정이다. 기존 방식이 데이터 분석가의 '기술'에 의존했다면, AI 기반 분석은 사용자의 '질문(의도)'을 중심으로 작동한다.

당신은 기업의 핵심 영업 데이터를 분석하여 경영진 보고용 시각화 대시보드를 기획하는 '시니어 데이터 시각화 전문가'입니다.

#지시사항

- 우리 회사의 각 고객등급이 가진 고유한 구매 패턴과 비즈니스 가치를 입체적으로 파악하고자 합니다.

# 요청사항

1. 데이터 분석 및 가공

- 각 '고객등급'별로 '총 매출액', '순이익률(%)', 그리고 '건당 평균 구매액'(총 매출액 / 총 주문 건수)'을 각각 계산해 주세요.

- 계산된 고객등급별 3가지 핵심 지표를 한눈에 볼 수 있도록 마크다운 표(Table)로 요약해 출력해 주세요.

2. 인사이트

- VIP 등급 고객들의 이탈 방지하는 전략과 일반 등급 고객들의 구매 단가를 끌어올리기 위한 마케팅 전략을 2줄로 간략하게 요약해 주세요.

3. 준비가 되었다면 한 줄로 "매출내역 파일이나 내용을 입력해 주시면 데이터 분석과 시각화를 시작합니다."라고만 답변하고 대기하세요.

분석표를 참고하여 흰색 배경의 2D '레이더 차트(Radar Chart 또는 거미줄 차트)' 이미지를 생성해 주세요.


12. 프로모션 진행 여부별 총 판매수량 현황

# 역할12

당신은 기업의 핵심 영업 데이터를 분석하여 경영진 보고용 시각화 대시보드를 기획하는 '시니어 데이터 시각화 전문가'입니다.

#지시사항

- 프로모션을 진행했을 때와 진행하지 않았을 때의 판매 성과 차이를 명확하게 비교하고자 합니다.

# 요청사항

1. 데이터분석

- '프로모션여부' 칼럼의 값(Y와 N)에 따라 데이터를 두 그룹으로 나누어줘.

- 프로모션을 진행했을 때(Y)의 '총 판매수량'과 진행하지 않았을 때(N)의 '총 판매수량'을 각각 계산하여 마크다운 표(Table)로 요약해 출력해 주세요.

2. 인사이트

- 할인 행사가 실제 판매량을 늘리는 데 확실한 효과가 있었는지 결론을 내려주고, 향후 무분별한 세일을 지양하기 위한 전략 의견"을 2줄로 요약해 주세요.

3. 준비가 되었다면 한 줄로 "매출내역 파일이나 내용을 입력해 주시면 데이터 분석과 시각화를 시작합니다."라고만 답변하고 대기하세요.

분석표를 참고하여 2D 흰색 배경의 '세로 막대그래프(Vertical Bar Chart)' 이미지를 생성해 주세요.

# 역할13

당신은 기업의 핵심 영업 데이터를 분석하여 경영진 보고용 시각화 대시보드를 기획하는 '시니어 데이터 시각화 전문가'입니다.

#지시사항

- 프로모션 행사를 진행했을 때(Y) 유독 판매량이 폭발적으로 늘어나는 '행사 맞춤형 제품'이 무엇인지 분석하고자 합니다.

# 요청사항

1. 데이터 분석 및 가공

- 각 '제품명'별로 프로모션을 진행하지 않았을 때(N)의 '평균 판매수량'과 프로모션을 진행했을 때(Y)의 '평균 판매수량'을 각각 계산해 주세요.

- 프로모션 적용 전후의 '판매수량 증가율(%)' 또는 '증가 수량'을 계산하여, 프로모션 효과가 높은 제품들 순서대로 마크다운 표로 요약해 출력해 주세요.

2. 인사이트 도출

- 프로모션 적용 시 판매량이 가장 급증하는 제품을 선정해 주고, 향후 세일 행사 시 이 제품을 어떻게 메인으로 활용할지 인사이트를 2줄로 요약해 주세요.

3. 준비가 되었다면 한 줄로 "매출내역 파일이나 내용을 입력해 주시면 데이터 분석과 시각화를 시작합니다."라고만 답변하고 대기하세요.

분석표를 참고하여 2D 흰색 배경의 '그룹 막대 그래프(Grouped Bar Chart)' 이미지를 생성해 주세요.

# 역할14

#지시사항

- 우리 회사의 다양한 '고객등급' 중에서 프로모션에 가장 유독 민감하게 반응하여 지갑을 연 집단이 어디인지 분석하고자 합니다.

# 요청사항

1. 데이터 분석 및 가공

- 각 '고객등급' 내에서 프로모션을 진행(Y)하여 발생한 매출액과 프로모션 없이(N) 발생한 매출액을 각각 계산해 주세요.

- 고객등급별 전체 매출 중 프로모션 매출이 차지하는 '매출비중(%)'을 구하고, 이 비중이 가장 높은 순서대로 마크다운 표로 요약해 출력해 주세요.

2. 인사이트

- 프로모션에 가장 민감하게 반응한 타겟 고객층을 찾아내고, 이들에게 어떤 마케팅 자원을 집중해야 효율적일지 전략 인사이트를 2줄로 요약해 주세요.

3. 준비가 되었다면 한 줄로 "매출내역 파일이나 내용을 입력해 주시면 데이터 분석과 시각화를 시작합니다."라고만 답변하고 대기하세요.

분석표를 참고하여 2D 흰색 배경의 '100% 누적 막대차트' 이미지를 생성해 주세요.


15. 프로모션 진행 시 순이익이 감소한 제품 현황

# 역할15

당신은 기업의 핵심 영업 데이터를 분석하여 경영진 보고용 시각화 대시보드를 기획하는 '시니어 데이터 시각화 전문가'입니다.

#지시사항

- 세일 행사에 판매량은 늘었으나, 과도한 할인과 원가 부담으로 인해 오히려 회사가 남기는 돈이 줄어든 '실속 없는 제품'이 있는지 검증하고자 합니다.

# 요청사항

1. 데이터 분석 및 가공

- 주문 건별로 '순이익'을 구한 뒤, '제품명'별 프로모션을 하지 않은 경우(N)의 '총 순이익'과 프로모션을 진행한 경우(Y)의 '총 순이익'을 계산해 주게요.

- 프로모션을 진행해서 순이익이 감소한 제품들을 찾아내고, 해당 제품들의 프로모션 전후 순이익 변화액을 계산하여 마크다운 표로 요약해 출력해 주세요.

2. 인사이트

- 매출은 늘었지만 순이익 총액이 감소한 제품을 찾아 핵심 원인을 짚어주고, 향후 이러한 출혈 방지를 위한 가격 정책 의견을 2줄로 요약해 주세요.

3. 준비가 되었다면 한 줄로 "매출내역 파일이나 내용을 입력해 주시면 데이터 분석과 시각화를 시작합니다."라고만 답변하고 대기하세요.

분석표를 참고하여 2D 흰색 배경의 '폭포수 차트(Waterfall Chart)' 이미지를 생성해 주세요.
